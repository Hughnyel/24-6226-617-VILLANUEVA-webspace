## Project Description

This project is a three-page personal website created using HTML and CSS. 
The website was developed and hosted using GitHub Codespaces and a Python HTTP server.

The website contains a Home page, About Me page, and Contact page. 
It also includes navigation links, student information, hobbies and interests, contact information, an image, and basic CSS styling.
